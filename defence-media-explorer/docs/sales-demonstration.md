# Five-minute demonstration

English script for an executive walkthrough. Say only what the screen shows. If Voyage or OpenAI is not configured, say the capability is unavailable. Do not quote a similarity percentage, a latency target, or a cross-language accuracy number.

**0:00 — Open the archive.** Sign in with the administrator the API seeded. If those two environment values are empty, say so and stop on the sign-in explanation rather than inventing a password. Land on Search. Hybrid is selected. Read one example aloud: “Tracked vehicles on muddy terrain during a training exercise.” Run it only if embeddings are configured. If they are not, the page names that embeddings are unavailable. That is the honest state.

**0:45 — Show a complete browse.** Clear the query. The count is a complete count of matching segments, and the line says so. Point at the time zone under the date filters. Change the zone in Settings if you want, then come back: the URL still holds the filters, and the zone on the filter did not follow the interface language.

**1:30 — Narrow the window.** Set the date field to capture date or upload date. Set unknown capture dates to include, exclude, or only. Add a media type. The chips are the active filters. Reset clears them.

**2:15 — Explain ranking without a score.** With a real query, read the retrieved-candidate line. It is the window that was ranked, not every match in the archive. If you sort that result by date, read the warning: the order applies inside the window. If the response includes elapsed milliseconds, read that figure. If it does not, do not supply one. Nearby video matches, when present, are grouped and counted on the card. Open, Find similar, and Details are the three actions.

**3:15 — Open one asset.** The player seeks to the segment time. Click a transcript line or a storyboard frame and the playhead moves. Open the technical record. It names the database `defence_media_explorer`, the `segments` collection, the indexing state, a short embedding preview, and the text fields Atlas Search uses. Say that a persisted write is not the same thing as the search index being queryable. Do not read out a full vector. There isn't one on the page.

**4:15 — Health and language.** Open Settings. Read the capabilities that are configured and the ones that are not. Host names and connection strings are not on this page. Switch the interface to Français or Deutsch. Labels wrap onto new lines. The archive text does not change, and neither do the embeddings. Switch back to English.

Close by naming the limit: semantic and cross-language retrieval exist in the product only when Voyage is configured, and this demonstration does not claim a quality score for them.
